# Kickstarter Campaign Analysis (Power BI)

An interactive Power BI dashboard analyzing 702K+ Kickstarter crowdfunding projects, built as a hands-on project during the ITI Power BI track.

![Dashboard Preview](screenshots/dashboard.png)

## Key Metrics
- **702K** projects and **73M** backers
- **$6.48bn** total pledged against a **$34bn** total goal

## What the Dashboard Shows
- Failed projects (0.37M) outnumber successful ones (0.25M)
- Film & Video is the largest category (121K projects), followed by Music (99K) and Publishing (74K)
- USD accounts for most of the pledged amount ($5.2bn)
- Number of projects over time, by year

## Process
1. Extracted raw data from two Excel files
2. Appended and cleaned the data using Power Query
3. Wrote DAX measures for the key metrics
4. Built the visuals and layout in Power BI Desktop

## Tools
Power BI, Power Query, DAX, Excel

## How to Open
Download `Kickstarter_Analysis.pbix` and open it with Power BI Desktop.
